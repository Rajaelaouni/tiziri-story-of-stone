# Tiziri Legacy

Crée un site web e-commerce PREMIUM, artistique, immersif et émotionnel pour une marque marocaine de bracelets artisanaux appelée :

TIZIRI

Créations d’Ahmed Tiziri

IMPORTANT :

Le site doit ressembler à une véritable marque internationale de bijoux artisanaux haut de gamme, et surtout PAS à une boutique e-commerce générique.

==================================================

1. TECHNOLOGIES

==================================================

Utilise obligatoirement :

- React

- Vite

- TypeScript

- Tailwind CSS

- React Router

- Lucide React pour les icônes

- Framer Motion pour les animations

Architecture propre et professionnelle.

Le code doit être :

- componentisé

- maintenable

- responsive

- accessible

- performant

- SEO-friendly

Prépare une architecture permettant d'ajouter facilement de nouveaux bracelets.

==================================================

2. IDENTITÉ DE MARQUE

==================================================

Nom :

TIZIRI

Sous-titre :

Créations d’Ahmed Tiziri

Signature :

"La nature a créé la matière.

Ahmed Tiziri lui a donné une histoire."

Slogan :

"Porter la nature. Porter une histoire."

Concept :

TIZIRI transforme des matières particulières inspirées de la nature en bracelets uniques.

La marque est profondément inspirée par Ourika et les paysages de l’Atlas :

- montagnes

- rivière

- pierres

- terre

- végétation

- lumière

- couleurs naturelles

TIZIRI ne vend pas simplement des bracelets.

TIZIRI raconte une histoire à travers chaque création.

5. IMAGE HERO FOURNIE

==================================================

La maquette Hero fournie doit servir de référence PRINCIPALE pour l'identité visuelle du site.

Respecter :

- composition

- ambiance

- palette

- hiérarchie

- navigation

- espace

- photographie immersive

- positionnement du texte

- esthétique premium

Ne pas simplement copier l'image.

Reproduire son langage visuel dans les autres pages.

IMPORTANT :

Les photos originales des bracelets fournies par l'utilisateur sont les PHOTOS RÉELLES DES PRODUITS.

Ne jamais remplacer un bracelet réel par un bracelet généré par IA.

Ne jamais modifier :

- nombre de perles

- couleurs

- forme

- matières

- fermoirs

- cordons

- charms

- disposition réelle des éléments

Les photos peuvent être améliorées visuellement avec :

- recadrage

- background

- lumière

- mise en page

- ombres

- environnement

mais le produit réel doit rester fidèle.

Ne jamais sacrifier le storytelling au profit de la quantité de produits.

Ne pas mettre trop de cartes.

Ne pas utiliser de design e-commerce générique.

Les photos doivent être grandes.

Les titres doivent être élégants.

Les espaces doivent être généreux.

Le site doit être visuellement proche d'une maison de joaillerie / artisanat premium internationale.
